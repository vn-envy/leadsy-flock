# Leadsy Flock — agents-cli spec

Approved by the founder on 2026-08-27 via the locked hackathon plan.
This file is the agents-cli source of truth for the day-1 scaffold.

## Problem

Small businesses cannot afford an AI SDR ($20k–65k/yr) or a CRM-suite
agent ($800+/mo). They need one chat message to become a complete,
accountable campaign. Leadsy is that agency.

## Day-1 agent (this scaffold)

- **Name:** Flo (director)
- **Framework:** Google ADK (`adk` template, A2A built in)
- **Model:** Gemini 3.5 Flash via Vertex AI (global)
- **Deployment:** Cloud Run, `asia-south1`, service `flock-api`
- **Sessions:** in-memory for day 1 (Memory Bank lands day 2)
- **Observability:** OpenTelemetry → Cloud Trace (`otel_to_cloud=True`)

## Tools (day 1)

- `list_flock` — static catalog of the eight birds
- `now_ist` — India Standard Time for deadline reasoning

No browser, no email, no payments on day 1.

## Safety

- Refuse cold outreach and guaranteed-result claims
- Discovery ≠ consent
- No PII collection beyond what the owner types in chat

## Later days (not this scaffold's job)

Pub/Sub worker, Scout/Inka/Stella/Ray, Creative Gate (Gemma + Gemini),
Ad Kit, Telegram, Mission Control, Memory Bank, Agent Registry, proof pack.
